# 감정일기

감정을 글로 적으며 스스로를 돌아보는 데스크톱 일기 앱입니다.
임상심리 수업에서 배운 **감정 일기**를 바탕으로, 인지행동치료(CBT)의
사고기록지 형식을 부담 없이 쓸 수 있게 옮겼습니다.

심리학과 학부 포트폴리오로 만든 개인 프로젝트입니다.

## 무엇을 할 수 있나요

- **일기 쓰기** — 사건·감정·생각 세 칸을 채우는 템플릿 작성과, 한 칸에
  자유롭게 쓰는 자율 작성 중에 고를 수 있어요. 그날의 기분을 -10 ~ +10
  척도로 함께 남깁니다.
- **감정 단어 자동 인식** — 적은 글에서 감정 단어를 찾아 색으로 표시하고
  집계합니다. "행복하지 않았다"처럼 **부정 표현은 빼고** 셉니다.
  "서러웠다 → 서럽다"처럼 활용형도 알아봅니다.
- **감정 단어집** — 카테고리별로 단어를 직접 추가·수정할 수 있어요.
  인식에 쓰이는 어간은 규칙 엔진이 자동으로 만들어 줍니다.
- **분석** — 주간·월간·연간으로 감정 카테고리 비율, 평균 기분, 가장 많이
  쓴 감정 표현을 봅니다.
- **찾아보기** — 리스트 뷰와 캘린더 뷰, 검색창 하나로 제목·날짜·감정 단어
  통합 검색, 즐겨찾기.
- **내보내기 / 백업** — 아래 "내 일기는 어디에 저장되나요" 참고.
- **라이트 / 다크 테마** — 사이드바 왼쪽 아래에서 바꿉니다.

## 내려받기

**[→ 최신 버전 받기](../../releases/latest)**

파이썬을 따로 깔지 않아도 됩니다. 설치 과정도 없습니다.

| | 받을 파일 | 실행 |
|---|---|---|
| Windows (64비트) | `EmotionDiary-1.0.0-win64.zip` | 압축을 풀고 `EmotionDiary.exe` |
| macOS (Apple Silicon) | `EmotionDiary-1.0.0-macOS-arm64.zip` | 압축을 풀고 `EmotionDiary.app` |

폴더째로 두고 쓰세요. `EmotionDiary.exe`만 따로 옮기면 열리지 않습니다
(옆의 `_internal` 폴더가 필요합니다). 바탕화면에 두고 쓰시려면 앱을 켠 뒤
왼쪽 메뉴의 **바탕화면 바로가기**를 누르세요.

처음 열 때 뜨는 보안 경고는 아래를 참고하세요 —
[Windows](#windows에서-배포본-열기) · [macOS](#macos에서-배포본-열기).

### Windows에서 배포본 열기

"Windows가 PC를 보호했습니다"라는 창이 뜰 수 있습니다. 개인이 만든
프로그램이라 코드 서명 인증서가 없어서 그렇고, 앱에 문제가 있다는 뜻은
아닙니다. **추가 정보 → 실행**을 누르면 열립니다.

## 소스로 실행하기

Python 3.12 기준입니다.

```bash
pip install -r requirements.txt
python main.py
```

외부 라이브러리는 **PySide6 하나**입니다. 나머지는 파이썬에 들어 있는
표준 라이브러리(`sqlite3`, `json`, `re` 등)만 씁니다.

Windows와 macOS(Apple Silicon)에서 돌아갑니다.

### macOS에서 배포본 열기

받은 zip을 풀고 `EmotionDiary.app`을 더블클릭하면 됩니다. 다만 **처음 열 때
"개발자를 확인할 수 없습니다"라는 경고**가 뜹니다. Apple 개발자 등록(연 $99)을
하지 않아 서명이 없어서 그렇고, 앱에 문제가 있다는 뜻은 아닙니다.

이렇게 열 수 있습니다.

1. 앱에 **마우스 오른쪽 버튼** → **열기**
2. 다시 나오는 창에서 **열기**를 한 번 더

한 번 이렇게 열어 두면 다음부터는 그냥 더블클릭하면 됩니다.
(위 방법으로 안 되면 **시스템 설정 → 개인정보 보호 및 보안**으로 가서
아래쪽 "확인 없이 열기"를 누르세요.)

⚠️ Apple Silicon(M1 이후) 전용입니다. 2020년 이전 Intel Mac에서는 열리지
않습니다. 그 경우 위의 소스 실행 방법을 쓰시면 됩니다.

## 내 일기는 어디에 저장되나요

일기는 **이 PC 안에만** 저장됩니다. 서버로 보내거나 인터넷에 올리지
않습니다 — 앱에는 네트워크에 접속하는 기능 자체가 없습니다.

| 실행 형태 | 저장 위치 |
|---|---|
| 배포본 (Windows) | `%LOCALAPPDATA%\감정일기\emotion_diary.db` |
| 배포본 (macOS) | `~/Library/Application Support/감정일기/emotion_diary.db` |
| 소스로 실행 | 프로젝트 폴더의 `emotion_diary.db` |

### ⚠️ 파일은 암호화되어 있지 않습니다

일기는 **암호화 없이** SQLite 파일에 저장됩니다. 그 파일을 열 수 있는
사람은 일기 내용을 볼 수 있습니다. 그래서:

- **PC를 다른 사람과 함께 쓴다면** Windows 사용자 계정을 따로 두시고,
  그 계정에 암호를 걸어 두세요. 위 저장 위치는 계정별로 분리됩니다.
- 파일을 **다른 사람에게 그대로 넘기지 마세요.** 남에게 보여줄 목적이라면
  '내보내기/백업 → 보기·공유용'으로 기간이나 즐겨찾기만 골라 문서를
  만드는 편이 안전합니다.

암호화를 넣지 않은 이유는 [설계 문서](감정일기_개발_구조(26.08.06ver).md)의
"결정 기록"에 적어 두었습니다.

### 백업을 권합니다

일기는 파일 하나에 들어 있어서, 그 파일이 지워지면 되돌릴 수 없습니다.
**내보내기/백업 → 백업** 에서 가끔 백업 파일(JSON)을 만들어 다른 곳에
보관해 두세요. PC를 바꾸거나 앱을 다시 설치할 때 그대로 복원됩니다.

백업 파일에도 일기 내용이 그대로 들어 있으니, 보관 위치는 저장 위치와
같은 기준으로 골라 주세요.

## 만든 방식

| 구분 | 선택 |
|---|---|
| 언어 | Python 3.12 |
| GUI | PySide6 (Qt for Python) — 한글 IME 인라인 조합을 온전히 지원 |
| 저장 | SQLite (파이썬 내장) |
| 차트 | QPainter로 직접 그림 |
| PDF | Qt 내장 `QPdfWriter` (외부 라이브러리 없음) |
| 감정 인식 | 규칙 기반 자모 매칭 (형태소 분석기 미사용) |

폴더 구조는 UI(`app/ui_qt`) · 서비스(`app/services`) · 데이터(`app/db`)
세 층으로 나눠 두었습니다. 자세한 설계 의도와 화면별 명세는
[설계 문서](감정일기_개발_구조(26.08.06ver).md)에 있습니다.

### 배포본 만들기

파이썬이 깔려 있지 않은 PC에서도 돌아가는 폴더형 배포본(zip)을 만듭니다.

```bash
pip install pyinstaller
python tools/build.py
```

**빌드는 그 운영체제에서 해야 합니다** — Windows에서 Mac용을, Mac에서
Windows용을 만들 수는 없습니다.

| 어디서 빌드 | 결과 |
|---|---|
| Windows | `dist/EmotionDiary/` + `EmotionDiary-1.0.0-win64.zip` (약 86MB / 압축 34MB) |
| macOS | `dist/EmotionDiary.app` + `EmotionDiary-1.0.0-macOS-arm64.zip` (약 99MB / 압축 35MB) |

- 아이콘과 라이선스 전문은 없으면 빌드 과정에서 자동으로 준비됩니다
  (`tools/make_icon.py`, `tools/fetch_licenses.py`).
- **단일 파일이 아니라 폴더형(onedir)** 입니다. Qt 라이브러리가 별도 파일로
  남아야 LGPL의 '라이브러리 교체 가능성' 조건을 지킬 수 있습니다.
  (macOS의 `.app`도 속을 보면 폴더입니다.)
- 빌드 설정은 `emotion_diary.spec`, 배포본에 들어가는 안내문은
  `packaging/README.txt` 에 있습니다.

#### Mac이 없다면

GitHub Actions가 대신 빌드합니다. 저장소의 **Actions 탭 → "테스트 · 배포본
빌드" → Run workflow**를 누르면 Apple Silicon용 `.app`을 만들어, 결과를
zip으로 내려받을 수 있게 올려 줍니다(Artifacts).

빌드한 앱이 실제로 열리는지도 그 안에서 확인합니다 — `tools/verify_app.py`가
저장 경로·일기 저장·화면 전환·내보내기까지 훑습니다. 다만 서버에는 화면이
없어서 **눈으로 보는 UI 확인은 되지 않습니다**.

DB·서비스 계층(감정 인식, 활용형 생성, 기간 분석, 백업 복원, 내보내기
문서 생성)을 덮고 있습니다.
